# Kuromi Art Gallery 🖤💜

Galeria interativa estilo Polaroid com estética Kuromi (arquitetura Mobile-First) para guardar desenhos, recados e datas.

## Estrutura do Repositório

- `frontend/`: Aplicação web (HTML, CSS Mobile-First, Vanilla JS) e pasta `assets/` (wallpapers e GIFs).
- `backend/`: Configurações de exemplo para Firebase e Cloudinary (`config.example.js`) e regras de segurança (`firestore.rules`).
- `vercel.json`: Define `frontend` como diretório público (`outputDirectory`) na Vercel.

## Como testar localmente

1. Abra `frontend/index.html` no navegador.
2. Digite o código secreto padrão: `kuromi`.
